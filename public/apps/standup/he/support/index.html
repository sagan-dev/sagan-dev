תמיכה

תשובות לשאלות נפוצות. עדיין נתקעת? כתוב לאימייל.

איך מתחברים לשולחן בפעם הראשונה?
  1. נתק את השולחן ממכשירים אחרים — למשל, סגור את אפליקציית השולחן בטלפון שלך. השולחן מתקשר עם מכשיר אחד בכל פעם.
  2. הפעל מצב התאמה (pairing): החזק את כפתור ה-Bluetooth בשלט השולחן למשך כ-3 שניות, עד שהאור הכחול מתחיל להבהב.
  3. פתח את Standup ואפשר Bluetooth כש-macOS מבקש.
  4. Standup מאתר את השולחן ומתחבר בעצמו — ב-popover מוצג "Connecting…" ואז שם השולחן. אין שלב התאמה נפרד ב-Mac.

אחרי זה, Standup מתחבר מחדש באופן אוטומטי בכל הפעלה ואחרי שה-Mac שלך מתעורר.

Standup לא מוצא את השולחן שלי

נסה את אלה בסדר הזה:

  1. סגור כל אפליקציה אחרת שמחוברת לשולחן (אפליקציה בטלפון, Mac אחר). השולחן מתקשר עם מכשיר אחד בכל פעם.
  2. אפשר Bluetooth עבור Standup בהגדרות המערכת → פרטיות ואבטחה → Bluetooth.
  3. ודא ששם השולחן ב-Bluetooth עדיין מכיל את המילה "Desk".
  4. הפעל מצב התאמה: החזק את כפתור ה-Bluetooth בשלט למשך כ-3 שניות, עד שהאור מהבהב.
  5. אפס את השולחן: הורד אותו עד הסוף, החזק את כפתור ההורדה עד שהשולחן מבצע קפיצה למטה ולמעלה, ואז החזק את כפתור ה-Bluetooth בשלט עד שהאור מהבהב, ופתח את Standup מחדש.
איך משתמשים בפגישות מ-Outlook?

Standup קורא את יומן macOS. הוסף את חשבון Outlook, Exchange או Microsoft 365 שלך בהגדרות המערכת → חשבונות אינטרנט וודא שהאפשרות לוח שנה מופעלת עבורו. החשבון יופיע אז באפליקציית לוח שנה, ו-Standup יראה את הפגישות שלו. אפשר גישה ליומן כש-Standup מבקש.

אילו פגישות מרימות את השולחן?

פגישות שיש להן משתתפים נוספים, שמכילות קישור לפגישה מקוונת (Teams, Meet, Zoom, Webex, Whereby או GoToMeeting) בכתובת ה-URL, במיקום או בהערות, ושאתה מארגן או שאישרת. אירועים של יום שלם, הזמנות שבוטלו, נדחו, אושרו באופן ארעי או שלא נענו, וכן אירועים המסומנים כ-"פנוי" מתעלמים מהם. השולחן מתחיל להתרומם כמה דקות לפני ההתחלה (אפשר לשנות את זמן ההקדמה בהעדפות).

למה השולחן לא זז בשביל הפגישה שלי?

בדוק שהתכונה מופעלת (Stand during meetings), שהפגישה עומדת בכללים שלמעלה, ושהשולחן מחובר. אם הורדת את השולחן בעצמך במהלך פגישה, Standup לא מרים אותו שוב לאותה פגישה.

מה הניד הקטן הזה לפני שהשולחן זז?

לפני תזוזה אוטומטית, השולחן מנענע פעמיים בכיוון שאליו הוא עומד לנוע, ומחכה שנייה, כך שהוא לעולם לא זז בלי אזהרה. כבה את זה בהעדפות באמצעות Nudge the desk before it moves. תזוזות שאתה מתחיל בעצמך הן תמיד מיידיות.

מה עושה זיהוי השיחות, והאם האודיו שלי מוקלט?

אם תפעיל את Keep raised while on a call, השולחן יישאר למעלה אחרי הזמן המתוכנן לסיום, כל עוד אפליקציית הפגישה עדיין משתמשת במיקרופון או ברמקול, ויירד זמן קצר אחרי שהם משתתקים. Standup רואה רק את העובדה שאפליקציה משתמשת באודיו ואיזו אפליקציה — הוא לעולם לא מקליט או מגיע לשום אודיו או וידאו, ואינו מבקש הרשאת מיקרופון או מצלמה.

השולחן נעצר קצת לפני או קצת אחרי גובה הפריסט שלי

Standup לומד כמה השולחן שלך ממשיך לנוע אחרי עצירה, ומתקן את עצמו אחרי כמה תזוזות. אם הסטייה נשארת גדולה מכחצי סנטימטר, כתוב לנו עם שני הגבהים.

אפשר לשלוט בשולחן מסקריפט או מ-Shortcuts?

כן. Standup מבין את הפקודות הבאות ב-AppleScript:

tell application "Standup" to move desk "stand"    -- או "sit", "up", "down"
tell application "Standup" to set desk height "120cm"  -- או "48in", או just "80"

ב-Shortcuts, הוסף פעולת הפעלת AppleScript עם אחת מהשורות האלה. macOS מבקש הרשאה פעם אחת לשליטה ב-Standup.

הפגישה הסתיימה מוקדם — אפשר שהשולחן יירד מהר יותר?

כן, כשהאפשרות Keep raised while on a call מופעלת. כשהמיקרופון והרמקול של אפליקציית הפגישה משתתקים לפני הזמן המתוכנן לסיום, התראה שואלת Meeting over? Lower the desk?. אחרי מחצית הזמן היא שואלת מיד; במחצית הראשונה של הפגישה היא מחכה שתי דקות של שקט, למקרה שהחיבור שלך רק התנתק לרגע. היא שואלת פעם אחת לפגישה ורק כל עוד השולחן למעלה.

האם Standup יכול להחליף סצנות ב-Home Assistant? (בקרוב)

בקרוב — עדיין לא קיים בגרסה הנוכחית ב-App Store. תוכל להזין כתובת webhook ב-Preferences → Webhook. כשהשולחן מתרומם לפגישה וכשהוא יורד אחריה, Standup שולח POST עם גוף JSON קטן:

{
  "app": "Standup",
  "event": "meeting_started",
  "source": "calendar",
  "meeting": "Weekly sync",
  "desk": "stand",
  "height_cm": 110.2,
  "timestamp": "2026-10-01T09:58:00Z"
}

event הוא meeting_started או meeting_ended, source הוא calendar או unplanned_call. הזזת השולחן בעצמך לא שולחת שום דבר. כפתור Send test בודק את החיבור.

ב-Home Assistant, צור אוטומציה עם טריגר webhook והפנה את Standup לכתובת http://homeassistant.local:8123/api/webhook/standup:

alias: Standup meetings
triggers:
  - trigger: webhook
    webhook_id: standup
    allowed_methods: [POST]
    local_only: true
actions:
  - choose:
      - conditions: "{{ trigger.json.event == 'meeting_started' }}"
        sequence:
          - action: scene.turn_on
            target: { entity_id: scene.office_meeting }
      - conditions: "{{ trigger.json.event == 'meeting_ended' }}"
        sequence:
          - action: scene.turn_on
            target: { entity_id: scene.office_focus }
איך אפשר לנסות את הסצנה שלי ב-Home Assistant עם "Send test"? (בקרוב)

כברירת מחדל Send test בודק רק את החיבור — הוא שולח "event": "test", שלא מתחיל פגישה. כדי להשתמש בכפתור כמתג הפעלה/כיבוי לסצנת הפגישה שלך, תן ל-webhook להפעיל עוזר (input_boolean) וחבר את הסצנה לעוזר הזה. הבדיקה הראשונה תדליק את הסצנה, השנייה תכבה אותה ותשחזר את התאורה. הכנס את זה לחבילה (package), לדוגמה packages/standup.yaml, והתאם את התאורה:

input_boolean:
  standup_meeting:
    name: "Standup meeting"

automation:
  - alias: "Standup - webhook"
    mode: queued
    triggers:
      - trigger: webhook
        webhook_id: standup-YOUR-RANDOM-ID
        allowed_methods: [POST]
        local_only: false
    actions:
      - choose:
          - conditions: "{{ trigger.json.event == 'meeting_started' }}"
            sequence:
              - action: input_boolean.turn_on
                target: { entity_id: input_boolean.standup_meeting }
          - conditions: "{{ trigger.json.event == 'meeting_ended' }}"
            sequence:
              - action: input_boolean.turn_off
                target: { entity_id: input_boolean.standup_meeting }
          # "Send test" מדליק את סצנת הפגישה, הבדיקה הבאה מכבה אותה
          - conditions: "{{ trigger.json.event == 'test' }}"
            sequence:
              - action: input_boolean.toggle
                target: { entity_id: input_boolean.standup_meeting }

  - alias: "Standup - meeting scene"
    triggers:
      - trigger: state
        entity_id: input_boolean.standup_meeting
        from: "off"
        to: "on"
    actions:
      # זכור את התאורה קודם, כדי שניתן יהיה לשחזר אותה בהמשך
      - action: scene.create
        data:
          scene_id: standup_before_meeting
          snapshot_entities: [light.living_room, light.hallway, light.desk_lamp]
      - action: light.turn_off
        target: { entity_id: [light.living_room, light.hallway] }
      - action: light.turn_on
        target: { entity_id: light.desk_lamp }

  - alias: "Standup - after the meeting"
    triggers:
      - trigger: state
        entity_id: input_boolean.standup_meeting
        from: "on"
        to: "off"
    conditions:
      - condition: template
        value_template: "{{ states.scene.standup_before_meeting is not none }}"
    actions:
      - action: scene.turn_on
        target: { entity_id: scene.standup_before_meeting }

טיפים:

  • השתמש ב-webhook_id ארוך ואקראי אם Home Assistant נגיש מהאינטרנט — הכתובת היא הדבר היחיד שמגן עליו.
  • אל תבדוק אם לסצנה השמורה יש את המצב unknown: סצנה שנוצרה באמצעות scene.create נשארת unknown עד שהיא בשימוש, כך שתנאי כזה היה מונע מהתאורה לחזור אי פעם.
  • לחץ Send test פעם אחת, המתן לסצנה, ואז לחץ שוב. לחיצות מהירות ומרובות יכולות לגרום לסצנה לזכור תאורה שכבר כבויה.
  • טען מחדש אוטומציות ועוזרים (או הפעל מחדש את Home Assistant) אחרי עריכת החבילה.
אפשר להזיז את השולחן עם קיצורי מקלדת?

כן, באמצעות אפליקציית Shortcuts. הכן קיצור אחד לכל פעולה:

  1. פתח את Shortcuts וצור קיצור חדש, לדוגמה "שולחן: עמידה".
  2. הוסף פעולת הפעלת AppleScript עם tell application "Standup" to move desk "stand". בשביל הקיצורים האחרים השתמש ב-"sit", "up" או "down".
  3. פתח את פרטי הקיצור (ⓘ), בחר הוספת קיצור מקלדת והקש על המקשים, לדוגמה ⌃⌥↑ / ⌃⌥↓ בשביל מעלה ומטה, ו-⌃⌥S / ⌃⌥D בשביל עמידה וישיבה.
  4. בפעם הראשונה שבה תשתמש בזה, אפשר ל-Shortcuts לשלוט ב-Standup.

הקיצורים פועלים בכל אפליקציה. up ו-down מזיזים את השולחן בכ-1 ס"מ בכל לחיצה; החזקת המקשים לא ממשיכה להזיז אותו.

איך מפעילים את Standup בעת הכניסה למערכת, או סוגרים אותו?

פתח את העדפות מתפריט ה-"…" ב-popover והפעל את Open at login. בחר Quit מאותו התפריט כדי לסגור את האפליקציה.
