Kebijakan Privasi

Berlaku mulai 29 September 2026

Singkatnya: Aplikasi Standup tidak mengumpulkan data pribadi apa pun. Tidak ada akun, analitik, pelacakan, atau server. Semua yang dilakukan aplikasi ini tetap berada di Mac Anda.

Siapa yang bertanggung jawab

Standup - Desk Remote Control dikembangkan oleh Michal Sagan (sagan.dev). Kontak: e-mail.

Apa yang diakses aplikasi, dan mengapa

  • Bluetooth. Hanya digunakan untuk menemukan dan berkomunikasi dengan meja Anda (membaca ketinggiannya, mengirim perintah gerak). Tidak ada yang dikirim ke tempat lain.
  • Kalender (hanya jika Anda mengaktifkan fitur rapat). Standup membaca acara kalender Anda secara lokal, melalui EventKit milik Apple, untuk menemukan rapat online yang Anda selenggarakan atau terima. Data acara digunakan di perangkat untuk menentukan kapan menggerakkan meja. Data ini tidak pernah disimpan di luar kalender sistem, tidak pernah diunggah, dan tidak pernah dibagikan. Ini termasuk akun seperti Outlook, Exchange, atau Microsoft 365 yang Anda tambahkan ke macOS.
  • Aktivitas audio (hanya jika Anda mengaktifkan deteksi panggilan). Standup hanya menanyakan ke macOS apakah ada aplikasi yang sedang menggunakan input audio (mikrofon) atau output (speaker), dan aplikasi mana. Standup tidak menangkap, merekam, mendengarkan, atau mengakses audio maupun video apa pun, dan tidak meminta izin mikrofon atau kamera.
  • Notifikasi (opsional). Notifikasi lokal, misalnya saran untuk menaikkan meja saat ada panggilan tak terjadwal. Notifikasi ini dibuat di Mac Anda dan tidak dikirim melalui server apa pun.
  • Pengaturan. Preferensi Anda (ketinggian, satuan, opsi) disimpan secara lokal di Mac Anda dalam preferensi aplikasi. Data ini tidak disinkronkan atau diunggah.

Apa yang tidak kami lakukan

  • Tidak ada data pribadi yang dikumpulkan, dikirim, dijual, atau dibagikan.
  • Tidak ada SDK analitik, iklan, pelacakan, profil, atau pelaporan crash. Aplikasi ini tidak berisi SDK pihak ketiga; helper buka-saat-login adalah komponen open-source lokal yang kecil.
  • Tidak ada akun pengguna dan tidak ada server yang kami operasikan untuk aplikasi ini. Aplikasi ini bekerja sepenuhnya secara offline.

Retensi data dan kendali Anda

Karena tidak ada yang keluar dari Mac Anda, tidak ada data yang kami simpan untuk diakses, dikoreksi, atau dihapus. Pengaturan lokal dapat dihapus dengan mereset preferensi aplikasi atau menghapus instalasinya. Anda dapat mencabut akses Bluetooth, Kalender, atau Notifikasi kapan saja di System Settings → Privacy & Security, dan mematikan fitur rapat, deteksi panggilan, serta saran di Preferensi.

GDPR

Standup tidak memproses data pribadi di server kami mana pun, sehingga tidak ada pemrosesan di pihak kami yang dapat dikenai permintaan akses, perbaikan, penghapusan, atau portabilitas. Jika Anda punya pertanyaan, tulis ke e-mail. Anda juga berhak mengajukan keluhan ke otoritas pelindungan data Anda (di Polandia: UODO).

Situs web ini

Halaman di sagan.dev/apps/standup bersifat statis dan tidak memasang cookie apa pun. Mereka menggunakan Cloudflare Web Analytics untuk menghitung kunjungan: layanan yang mengutamakan privasi, tanpa cookie, tanpa fingerprinting, dan tanpa pelacakan lintas situs, serta tidak menyimpan apa pun di perangkat Anda. Cloudflare memproses data teknis permintaan standar (seperti halaman yang dikunjungi, referrer, jenis browser, dan negara) hanya untuk menghasilkan statistik agregat; lihat kebijakan privasi Cloudflare. Seperti penyedia hosting web lainnya, penyedia hosting (Vercel) juga dapat memproses log server teknis seperti alamat IP untuk menyajikan dan mengamankan situs ini. Hal ini hanya berlaku untuk situs web ini; aplikasi Standup sendiri tidak berisi analitik apa pun.

Anak-anak

Standup adalah aplikasi utilitas dan tidak ditujukan untuk anak-anak. Aplikasi ini tidak secara sengaja mengumpulkan data dari siapa pun.

Perubahan

Jika kebijakan ini berubah, versi baru akan dipublikasikan di halaman ini dengan tanggal yang diperbarui.
