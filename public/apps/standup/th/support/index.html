การสนับสนุน

คำตอบสำหรับคำถามที่พบบ่อย ยังติดปัญหาอยู่ไหม เขียนมาที่ อีเมล.

ฉันจะเชื่อมต่อโต๊ะของฉันครั้งแรกได้อย่างไร
  1. ยกเลิกการเชื่อมต่อโต๊ะจากอุปกรณ์อื่น ๆ ก่อน — เช่น ปิดแอปควบคุมโต๊ะบนโทรศัพท์ของคุณ เพราะโต๊ะเชื่อมต่อกับอุปกรณ์ได้ทีละเครื่องเท่านั้น
  2. เปิดโหมดจับคู่: กดปุ่ม Bluetooth บนตัวควบคุมของโต๊ะค้างไว้ประมาณ 3 วินาที จนไฟสีน้ำเงินเริ่มกะพริบ
  3. เปิด Standup และอนุญาตให้ใช้ Bluetooth เมื่อ macOS ถามสิทธิ์
  4. Standup จะค้นหาโต๊ะและเชื่อมต่อเองโดยอัตโนมัติ — ป็อปโอเวอร์จะแสดง "Connecting…" จากนั้นจะแสดงชื่อโต๊ะ ไม่มีขั้นตอนจับคู่แยกต่างหากบน Mac

หลังจากนั้น Standup จะเชื่อมต่อใหม่โดยอัตโนมัติทุกครั้งที่เปิดแอปและหลังจาก Mac ของคุณตื่นจากโหมดพัก

Standup หาโต๊ะของฉันไม่เจอ

ลองทำตามลำดับนี้:

  1. ปิดแอปอื่นที่เชื่อมต่อกับโต๊ะอยู่ (แอปบนโทรศัพท์ หรือ Mac อีกเครื่อง) เพราะโต๊ะเชื่อมต่อกับอุปกรณ์ได้ทีละเครื่องเท่านั้น
  2. อนุญาตให้ Standup ใช้ Bluetooth ที่ System Settings → Privacy & Security → Bluetooth.
  3. ตรวจสอบว่าชื่อของโต๊ะใน Bluetooth ยังมีคำว่า "Desk" อยู่
  4. เปิดโหมดจับคู่: กดปุ่ม Bluetooth บนตัวควบคุมค้างไว้ประมาณ 3 วินาที จนไฟกะพริบ
  5. รีเซ็ตโต๊ะ: ลดโต๊ะลงจนสุด กดปุ่มลดระดับค้างไว้จนโต๊ะเด้งลงแล้วขึ้น จากนั้นกดปุ่ม Bluetooth บนตัวควบคุมค้างไว้จนไฟกะพริบ แล้วเปิด Standup อีกครั้ง
ฉันจะใช้งานการประชุมจาก Outlook ได้อย่างไร

Standup อ่านข้อมูลจาก Calendar ของ macOS เพิ่มบัญชี Outlook, Exchange หรือ Microsoft 365 ของคุณได้ที่ System Settings → Internet Accounts และตรวจสอบให้แน่ใจว่าเปิดใช้งาน Calendars สำหรับบัญชีนั้นแล้ว จากนั้นบัญชีจะปรากฏในแอป Calendar และ Standup จะมองเห็นการประชุมของบัญชีนั้น อนุญาตให้เข้าถึงปฏิทินเมื่อ Standup ขอสิทธิ์

การประชุมแบบใดที่จะทำให้โต๊ะยกขึ้น

การประชุมที่มีผู้เข้าร่วมคนอื่น มีลิงก์ประชุมออนไลน์ (Teams, Meet, Zoom, Webex, Whereby หรือ GoToMeeting) อยู่ใน URL ตำแหน่งที่ตั้ง หรือบันทึกย่อ และเป็นการประชุมที่คุณเป็นผู้จัดหรือได้ตอบรับไว้ กิจกรรมที่กินเวลาทั้งวัน ถูกยกเลิก ปฏิเสธ ตอบรับแบบไม่แน่ใจ หรือยังไม่ได้ตอบรับ รวมถึงกิจกรรมที่ทำเครื่องหมายว่า "ว่าง" จะถูกข้ามไป โต๊ะจะเริ่มยกขึ้นก่อนเวลาเริ่มไม่กี่นาที (สามารถเปลี่ยนระยะเวลาล่วงหน้านี้ได้ในการตั้งค่า)

ทำไมโต๊ะไม่ขยับในการประชุมของฉัน

ตรวจสอบว่าเปิดใช้ฟีเจอร์นี้แล้ว (Stand during meetings) การประชุมตรงกับกฎข้างต้น และโต๊ะเชื่อมต่ออยู่ หากคุณลดโต๊ะลงเองระหว่างการประชุม Standup จะไม่ยกโต๊ะขึ้นอีกสำหรับการประชุมนั้น

สัญญาณสะกิดเล็ก ๆ ก่อนโต๊ะขยับคืออะไร

ก่อนการขยับโต๊ะแบบอัตโนมัติ โต๊ะจะสะกิดสองครั้งไปในทิศทางที่กำลังจะเคลื่อนที่ และรอหนึ่งวินาที เพื่อไม่ให้ขยับโดยไม่มีการเตือนล่วงหน้า ปิดฟีเจอร์นี้ได้ในการตั้งค่าด้วยตัวเลือก Nudge the desk before it moves. ส่วนการขยับที่คุณสั่งเองจะเกิดขึ้นทันทีเสมอ

การตรวจจับการโทรทำอะไร และเสียงของฉันถูกบันทึกหรือไม่

หากคุณเปิด Keep raised while on a call โต๊ะจะยังคงอยู่ในสถานะยืนต่อไปหลังเวลาสิ้นสุดที่กำหนด ตราบที่แอปประชุมยังใช้ไมโครโฟนหรือลำโพงอยู่ และจะลดลงไม่นานหลังจากเงียบลง Standup รู้เพียงว่ามีแอปใช้เสียงอยู่และเป็นแอปใด — ไม่เคยบันทึกหรือเข้าถึงเสียงหรือวิดีโอใด ๆ และไม่ขอสิทธิ์เข้าถึงไมโครโฟนหรือกล้อง

โต๊ะหยุดก่อนหรือเกินความสูงที่ตั้งพรีเซ็ตไว้เล็กน้อย

Standup เรียนรู้ว่าโต๊ะของคุณเลื่อนต่อไปอีกเท่าใดหลังจากหยุด และจะปรับแก้ให้เองหลังจากขยับไม่กี่ครั้ง หากยังคลาดเคลื่อนมากกว่าประมาณครึ่งเซนติเมตร ส่งข้อความมาบอกเราพร้อมระบุทั้งสองความสูง

ฉันสามารถควบคุมโต๊ะจากสคริปต์หรือ Shortcuts ได้หรือไม่

ได้ Standup เข้าใจคำสั่ง AppleScript เหล่านี้:

tell application "Standup" to move desk "stand"    -- หรือ "sit", "up", "down"
tell application "Standup" to set desk height "120cm"  -- หรือ "48in", หรือแค่ "80"

ใน Shortcuts ให้เพิ่มแอ็กชัน เรียกใช้ AppleScript พร้อมหนึ่งในบรรทัดเหล่านี้ macOS จะถามสิทธิ์ควบคุม Standup เพียงครั้งเดียว

การประชุมจบเร็วกว่ากำหนด — โต๊ะสามารถลดลงเร็วขึ้นได้หรือไม่

ได้ หากเปิด Keep raised while on a call ไว้ เมื่อไมโครโฟนและลำโพงของแอปประชุมเงียบลงก่อนเวลาสิ้นสุดที่กำหนด การแจ้งเตือนจะถาม Meeting over? Lower the desk?. หากผ่านครึ่งเวลาไปแล้วจะถามทันที แต่ถ้าอยู่ในช่วงครึ่งแรกของการประชุมจะรอเงียบไปสองนาทีก่อน เผื่อว่าการเชื่อมต่อของคุณหลุดไปชั่วคราว การแจ้งเตือนนี้จะถามเพียงครั้งเดียวต่อการประชุม และเฉพาะตอนที่โต๊ะอยู่ในสถานะยืนเท่านั้น

Standup สามารถสลับฉากใน Home Assistant ได้หรือไม่ (เร็ว ๆ นี้)

เร็ว ๆ นี้ — ยังไม่มีในรุ่นปัจจุบันบน App Store ในอนาคตคุณจะสามารถกรอก URL ของ webhook ได้ที่ Preferences → Webhook. เมื่อโต๊ะยกขึ้นสำหรับการประชุมและเมื่อลดลงภายหลัง Standup จะส่งคำขอ POST พร้อมเนื้อหา JSON เล็ก ๆ ดังนี้:

{
  "app": "Standup",
  "event": "meeting_started",
  "source": "calendar",
  "meeting": "Weekly sync",
  "desk": "stand",
  "height_cm": 110.2,
  "timestamp": "2026-10-01T09:58:00Z"
}

event มีค่าเป็น meeting_started หรือ meeting_ended, source มีค่าเป็น calendar หรือ unplanned_call. การขยับโต๊ะด้วยตัวเองจะไม่ส่งข้อมูลใด ๆ ปุ่ม Send test ใช้ตรวจสอบการเชื่อมต่อ

ใน Home Assistant ให้สร้างออโตเมชันที่มีทริกเกอร์เป็น webhook แล้วตั้งค่าใน Standup ให้ชี้ไปที่ http://homeassistant.local:8123/api/webhook/standup:

alias: Standup meetings
triggers:
  - trigger: webhook
    webhook_id: standup
    allowed_methods: [POST]
    local_only: true
actions:
  - choose:
      - conditions: "{{ trigger.json.event == 'meeting_started' }}"
        sequence:
          - action: scene.turn_on
            target: { entity_id: scene.office_meeting }
      - conditions: "{{ trigger.json.event == 'meeting_ended' }}"
        sequence:
          - action: scene.turn_on
            target: { entity_id: scene.office_focus }
ฉันจะทดสอบฉากใน Home Assistant ด้วย "Send test" ได้อย่างไร (เร็ว ๆ นี้)

ตามค่าเริ่มต้น Send test จะตรวจสอบการเชื่อมต่อเท่านั้น — โดยส่ง "event": "test", ซึ่งไม่ได้เริ่มการประชุมแต่อย่างใด หากต้องการใช้ปุ่มนี้เป็นสวิตช์เปิด/ปิดสำหรับฉากการประชุมของคุณ ให้ webhook ควบคุมตัวช่วย (input_boolean) แล้วผูกฉากเข้ากับตัวช่วยนั้น การทดสอบครั้งแรกจะเปิดฉาก ครั้งที่สองจะปิดฉากและคืนค่าไฟกลับเหมือนเดิม นำโค้ดนี้ไปวางในแพ็กเกจ (เช่น packages/standup.yaml) แล้วปรับส่วนไฟให้ตรงกับของคุณ:

input_boolean:
  standup_meeting:
    name: "Standup meeting"

automation:
  - alias: "Standup - webhook"
    mode: queued
    triggers:
      - trigger: webhook
        webhook_id: standup-YOUR-RANDOM-ID
        allowed_methods: [POST]
        local_only: false
    actions:
      - choose:
          - conditions: "{{ trigger.json.event == 'meeting_started' }}"
            sequence:
              - action: input_boolean.turn_on
                target: { entity_id: input_boolean.standup_meeting }
          - conditions: "{{ trigger.json.event == 'meeting_ended' }}"
            sequence:
              - action: input_boolean.turn_off
                target: { entity_id: input_boolean.standup_meeting }
          # "Send test" จะเปิดฉากการประชุม การทดสอบครั้งต่อไปจะปิดฉาก
          - conditions: "{{ trigger.json.event == 'test' }}"
            sequence:
              - action: input_boolean.toggle
                target: { entity_id: input_boolean.standup_meeting }

  - alias: "Standup - meeting scene"
    triggers:
      - trigger: state
        entity_id: input_boolean.standup_meeting
        from: "off"
        to: "on"
    actions:
      # จดจำสถานะไฟก่อน เพื่อให้สามารถคืนค่ากลับได้ภายหลัง
      - action: scene.create
        data:
          scene_id: standup_before_meeting
          snapshot_entities: [light.living_room, light.hallway, light.desk_lamp]
      - action: light.turn_off
        target: { entity_id: [light.living_room, light.hallway] }
      - action: light.turn_on
        target: { entity_id: light.desk_lamp }

  - alias: "Standup - after the meeting"
    triggers:
      - trigger: state
        entity_id: input_boolean.standup_meeting
        from: "on"
        to: "off"
    conditions:
      - condition: template
        value_template: "{{ states.scene.standup_before_meeting is not none }}"
    actions:
      - action: scene.turn_on
        target: { entity_id: scene.standup_before_meeting }

คำแนะนำ:

  • ใช้ webhook_id แบบสุ่มที่ยาวพอ หากเข้าถึง Home Assistant ได้จากอินเทอร์เน็ต — เพราะ URL เป็นสิ่งเดียวที่ปกป้องมันอยู่
  • อย่าตรวจสอบสถานะ unknown ของฉากที่บันทึกไว้: ฉากที่สร้างโดย scene.create จะมีสถานะ unknown จนกว่าจะถูกใช้งาน หากตั้งเงื่อนไขแบบนั้นจะทำให้ไฟไม่สามารถคืนค่ากลับได้เลย
  • คลิก Send test ครั้งเดียว รอให้ฉากทำงาน แล้วจึงคลิกอีกครั้ง การคลิกซ้ำ ๆ อย่างรวดเร็วอาจทำให้ฉากจดจำไฟที่ดับอยู่แล้วไว้แทน
  • โหลดออโตเมชันและตัวช่วยใหม่ (หรือรีสตาร์ท Home Assistant) หลังจากแก้ไขแพ็กเกจ
ฉันสามารถขยับโต๊ะด้วยแป้นพิมพ์ลัดได้หรือไม่

ได้ ผ่านแอป Shortcuts สร้างชอร์ตคัตแยกสำหรับแต่ละการทำงาน:

  1. เปิด Shortcuts และสร้างชอร์ตคัตใหม่ เช่น "Desk: stand".
  2. เพิ่มแอ็กชัน เรียกใช้ AppleScript พร้อมคำสั่ง tell application "Standup" to move desk "stand". สำหรับชอร์ตคัตอื่น ๆ ให้ใช้ "sit", "up" หรือ "down".
  3. เปิดรายละเอียดของชอร์ตคัต (ⓘ) เลือก เพิ่มแป้นพิมพ์ลัด แล้วกดปุ่มที่ต้องการ เช่น ⌃⌥↑ / ⌃⌥↓ สำหรับขึ้นและลง และ ⌃⌥S / ⌃⌥D สำหรับ stand และ sit
  4. ในการใช้งานครั้งแรก ให้อนุญาตให้ Shortcuts ควบคุม Standup

ชอร์ตคัตเหล่านี้ใช้งานได้ในทุกแอป up และ down จะขยับโต๊ะประมาณ 1 ซม. ต่อการกดหนึ่งครั้ง การกดปุ่มค้างไว้จะไม่ทำให้โต๊ะขยับต่อเนื่อง

ฉันจะเริ่ม Standup ตอนเข้าสู่ระบบ หรือปิดแอปได้อย่างไร

เปิด การตั้งค่า จากเมนู "…" ในป็อปโอเวอร์ แล้วเปิดใช้งาน Open at login. เลือก Quit จากเมนูเดียวกันเพื่อปิดแอป
