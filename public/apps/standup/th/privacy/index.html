นโยบายความเป็นส่วนตัว

มีผลบังคับใช้ตั้งแต่วันที่ 29 กันยายน 2026

โดยสรุป: แอป Standup ไม่เก็บข้อมูลส่วนบุคคลใด ๆ ไม่มีระบบบัญชีผู้ใช้ ไม่มีการวิเคราะห์ข้อมูล ไม่มีการติดตาม และไม่มีเซิร์ฟเวอร์ ทุกอย่างที่แอปทำจะอยู่บน Mac ของคุณเท่านั้น

ผู้รับผิดชอบ

Standup - Desk Remote Control พัฒนาโดย Michal Sagan (sagan.dev) ติดต่อได้ที่: อีเมล.

แอปเข้าถึงอะไร และเพราะอะไร

  • Bluetooth ใช้เพียงเพื่อค้นหาและสื่อสารกับโต๊ะของคุณ (อ่านค่าความสูง ส่งคำสั่งเคลื่อนที่) ไม่มีการส่งข้อมูลไปที่อื่นใด
  • ปฏิทิน (เฉพาะเมื่อคุณเปิดใช้ฟีเจอร์เกี่ยวกับการประชุม) Standup อ่านข้อมูลกิจกรรมในปฏิทินของคุณในเครื่อง ผ่าน EventKit ของ Apple เพื่อค้นหาการประชุมออนไลน์ที่คุณเป็นผู้จัดหรือได้ตอบรับไว้ ข้อมูลกิจกรรมจะถูกใช้บนอุปกรณ์ของคุณเองเพื่อตัดสินใจว่าจะขยับโต๊ะเมื่อใด ข้อมูลนี้จะไม่ถูกเก็บไว้นอกปฏิทินของระบบ ไม่ถูกอัปโหลด และไม่ถูกแบ่งปันกับใคร รวมถึงบัญชีอย่าง Outlook, Exchange หรือ Microsoft 365 ที่คุณเพิ่มไว้ใน macOS ด้วย
  • กิจกรรมเสียง (เฉพาะเมื่อคุณเปิดใช้การตรวจจับการโทร) Standup สอบถาม macOS เพียงว่ามีแอปใดกำลังใช้อินพุตเสียง (ไมโครโฟน) หรือเอาต์พุตเสียง (ลำโพง) อยู่หรือไม่ และเป็นแอปใด แอปนี้ ไม่บันทึก ไม่ดักฟัง และไม่เข้าถึงเสียงหรือวิดีโอใด ๆ ทั้งสิ้น และไม่ขอสิทธิ์เข้าถึงไมโครโฟนหรือกล้อง
  • การแจ้งเตือน (ไม่บังคับ) การแจ้งเตือนในเครื่อง เช่น คำแนะนำให้ยกโต๊ะขึ้นระหว่างการโทรที่ไม่ได้วางแผนไว้ การแจ้งเตือนเหล่านี้สร้างขึ้นบน Mac ของคุณ และไม่ถูกส่งผ่านเซิร์ฟเวอร์ใด ๆ
  • การตั้งค่า การตั้งค่าของคุณ (ความสูง หน่วยวัด ตัวเลือกต่าง ๆ) ถูกจัดเก็บไว้ในเครื่อง Mac ของคุณภายในไฟล์การตั้งค่าของแอป โดยไม่มีการซิงค์หรืออัปโหลด

สิ่งที่เราไม่ทำ

  • ไม่มีการเก็บ ส่ง ขาย หรือแบ่งปันข้อมูลส่วนบุคคลใด ๆ
  • ไม่มี SDK สำหรับการวิเคราะห์ข้อมูล การโฆษณา การติดตาม การสร้างโปรไฟล์ หรือการรายงานข้อขัดข้อง แอปนี้ไม่มี SDK จากบุคคลที่สาม ส่วนตัวช่วยเปิดแอปพร้อมการเข้าสู่ระบบเป็นคอมโพเนนต์โอเพนซอร์สขนาดเล็กที่ทำงานในเครื่อง
  • ไม่มีระบบบัญชีผู้ใช้ และไม่มีเซิร์ฟเวอร์ที่เราดำเนินการสำหรับแอปนี้ แอปทำงานได้อย่างสมบูรณ์แบบออฟไลน์

การเก็บรักษาข้อมูลและการควบคุมของคุณ

เนื่องจากไม่มีข้อมูลใดออกจาก Mac ของคุณเลย เราจึงไม่มีข้อมูลใด ๆ ที่จะให้เข้าถึง แก้ไข หรือลบได้ การตั้งค่าในเครื่องสามารถลบได้โดยรีเซ็ตการตั้งค่าของแอปหรือถอนการติดตั้งแอป คุณสามารถเพิกถอนสิทธิ์เข้าถึง Bluetooth ปฏิทิน หรือการแจ้งเตือนได้ทุกเมื่อที่ System Settings → Privacy & Security และปิดฟีเจอร์เกี่ยวกับการประชุม การตรวจจับการโทร และคำแนะนำต่าง ๆ ได้ในการตั้งค่า

GDPR

Standup ไม่ประมวลผลข้อมูลส่วนบุคคลบนเซิร์ฟเวอร์ใด ๆ ของเรา ดังนั้นจึงไม่มีการประมวลผลในฝั่งของเราที่จะอยู่ภายใต้คำขอเข้าถึง แก้ไข ลบ หรือโอนย้ายข้อมูล หากมีคำถาม สามารถเขียนมาที่ อีเมล. คุณยังมีสิทธิ์ยื่นเรื่องร้องเรียนต่อหน่วยงานกำกับดูแลด้านการคุ้มครองข้อมูลของคุณ (ในโปแลนด์คือ UODO)

เว็บไซต์นี้

หน้าเว็บที่ sagan.dev/apps/standup เป็นหน้าเว็บสแตติกและไม่ได้ตั้งค่าคุกกี้ใด ๆ หน้าเว็บเหล่านี้ใช้ Cloudflare Web Analytics เพื่อนับจำนวนผู้เข้าชม ซึ่งเป็นบริการที่ให้ความสำคัญกับความเป็นส่วนตัวเป็นอันดับแรก ไม่ใช้คุกกี้ ไม่ใช้ fingerprinting และไม่มีการติดตามข้ามเว็บไซต์ รวมถึงไม่จัดเก็บสิ่งใดไว้บนอุปกรณ์ของคุณ Cloudflare ประมวลผลข้อมูลคำขอทางเทคนิคมาตรฐาน (เช่น หน้าที่เข้าชม ผู้อ้างอิง ประเภทเบราว์เซอร์ และประเทศ) เพื่อสร้างสถิติแบบรวมเท่านั้น ดูรายละเอียดได้ที่ นโยบายความเป็นส่วนตัวของ Cloudflare. เช่นเดียวกับผู้ให้บริการเว็บโฮสติ้งทั่วไป ผู้ให้บริการโฮสติ้ง (Vercel) อาจประมวลผลล็อกเซิร์ฟเวอร์ทางเทคนิค เช่น ที่อยู่ IP เพื่อให้บริการและรักษาความปลอดภัยของเว็บไซต์ ข้อมูลนี้เกี่ยวข้องกับเว็บไซต์นี้เท่านั้น ตัวแอป Standup เองไม่มีการวิเคราะห์ข้อมูลใด ๆ

เด็ก

Standup เป็นแอปเครื่องมือและไม่ได้มุ่งเป้าไปที่เด็ก แอปนี้ไม่เก็บข้อมูลจากผู้ใดโดยเจตนา
